# Getting Started

Install `@fsegurai/manifest-generator` and point it at your **docs** folder. It writes a `manifest.json`
for navigation and a `search-index.json` for search, next to your Markdown files.

## Installation

Run `npm install -D @fsegurai/manifest-generator`.

## First manifest

Run `npx manifest-generator ./docs` and open the generated files.
